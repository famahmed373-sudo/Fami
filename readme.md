# FAMI Rent Management<br/><br/>A simplified web application for managing shop rentals and payments, built with vanilla JavaScript and Supabase.<br/><br/>## Features<br/><br/>*   **Shop Management:** Register, edit, and manage shop details and tenant information.<br/>*   **Rent Collection:** Record payments (full or partial), view payment history.<br/>*   **Arrears Tracking:** Monitor outstanding rent balances per shop.<br/>*   **User Roles:** Admin, Manager, Payment Officer, Viewer with role-based access control.<br/>*   **Audit Trail:** Track all significant actions performed in the system.<br/>*   **Real-time Notifications:** Instant alerts for important events.<br/>*   **Reporting:** Monthly collection performance reports.<br/><br/>## Technologies Used<br/><br/>*   **Frontend:** HTML, CSS, Vanilla JavaScript<br/>*   **Backend:** Supabase (PostgreSQL, Authentication, Realtime, RPCs)<br/>*   **Deployment:** Vercel<br/><br/>## Getting Started<br/><br/>### 1.
